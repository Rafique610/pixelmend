# Application Frontend (React + Tailwind CSS)

## Overview
Unified modern web interface designed in Google Stitch, implemented with React (Vite + TypeScript) and styled with Tailwind CSS.

## Workspaces
1. **Universal Restoration**: Upload corrupted image or apply artificial corruptions, restore with universal autoencoder, inspect absolute error map and latency.
2. **Hard-Routed Restoration**: Inspect 4-class classifier probability breakdown, predicted label, selected specialist, and restored output.
3. **Soft Mixture-of-Experts Restoration**: Inspect continuous gating weights across all four branches, view dominant expert highlights, and view blended output.
4. **Face-to-Sketch Generator**: Upload portrait or capture via webcam, choose Style 1/2/3, view side-by-side output, and download generated sketch.
